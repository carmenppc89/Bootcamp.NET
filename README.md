This repository contains all the projects built during my **C# and SQL specialization bootcamp**. It reflects the full progression of the course: from basic console exercises to graphical desktop apps (WinForms), database access (Entity Framework / LINQ) and web applications (ASP.NET).

Each folder holds a standalone project with its own `README.md` explaining the goal, the logic implemented and the concepts practiced.

> Note: class and variable names inside the source code are in Spanish (the language the bootcamp was taught in); documentation is kept in English for accessibility.

## Tech stack

- **Language:** C#
- **Framework:** .NET Framework 4.7.2
- **Paradigms:** Object-Oriented Programming, inheritance, polymorphism, generics
- **Persistence:** JSON (Newtonsoft.Json), soon SQL Server / Entity Framework
- **IDE:** Visual Studio

## Learning progression

This repository also works as a learning log: each block builds on the previous one (basic syntax → classes and collections → inheritance and polymorphism → data persistence → graphical interfaces → web applications).
