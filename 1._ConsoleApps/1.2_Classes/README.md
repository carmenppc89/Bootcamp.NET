# 1.2 Classes

## Goal
Introduction to Object-Oriented Programming: defining custom classes, encapsulation with properties, overloaded constructors and collections of objects.

## Projects

| Project | Description |
|---|---|
| [Cards and Decks](./CarmenPPerez_CartasYBarajas) | Models a standard 52-card deck with shuffling and drawing operations |
| [Card Battle](./CarmenPPerez_BatallaDeCartas) | Multiplayer "War" card game with tie-breaking logic |
| [Football Club](./ClubDeFutbol) | Club, team, player and match manager with JSON persistence |

## Concepts practiced
- Classes, properties (`get`/`set`) and constructors
- Generic collections (`List<T>`)
- Object composition (a `Player` has a `Deck`, a `Club` has `Teams`...)
- JSON serialization with `Newtonsoft.Json`
